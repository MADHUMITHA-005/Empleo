# Empleo - Resume Builder

Empleo is a simple web-based resume builder.

## Technologies

- HTML
- CSS
- JavaScript
- Java
- MySQL

## Features

- Resume creation
- Personal information
- Education
- Skills
- Projects
- Experience
- Certifications
- Achievements
- Live resume preview
- Local storage
- MySQL database storage
- Print / Save as PDF

## Architecture

User
↓
HTML / CSS / JavaScript
↓
Java Backend
↓
MySQL Database

## How it works

1. User enters resume information.
2. JavaScript collects the data.
3. Data is sent to the Java backend.
4. Java processes the request.
5. Java connects to MySQL using JDBC.
6. Resume information is stored in the database.
